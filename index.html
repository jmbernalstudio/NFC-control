Cómo leer una tarjeta con tu iPhone

iOS no deja que ninguna web use el lector NFC. La lectura real la hace una app gratuita de lectura y NFC Control guarda y analiza el resultado, cifrado y en este dispositivo.

  1. Lee la tarjeta con NFC Tools o NFC TagInfo by NXP: pulsa «Leer» o «Scan» y acerca la tarjeta a la parte superior trasera del iPhone.
  2. Copia o comparte el informe. En TagInfo, activa Full Scan y usa Compartir → Guardar en Archivos. En NFC Tools, mantén pulsado sobre los datos para copiarlos o exporta el volcado de memoria.
  3. Impórtalo aquí: pega el texto o elige el archivo. NFC Control identifica el chip, el UID, el NDEF y qué operaciones están realmente disponibles.

Lectura directa disponible

Este navegador admite Web NFC. Pulsa «Escanear NFC» y acerca una etiqueta. Web NFC solo lee el número de serie y el mensaje NDEF: los sectores cifrados nunca son accesibles.
